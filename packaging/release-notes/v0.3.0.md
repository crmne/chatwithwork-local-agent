## Fixed

- **The desktop app is included when you install the package.** All three AUR variants, `.deb`, `.rpm`, the Windows MSI, the macOS `.pkg`, Homebrew, Scoop, Nix and the one-line installers now include the GUI alongside the terminal interface and daemon. Linux packages install the launcher and icon; Windows gets separate desktop and terminal Start menu entries; the macOS installer puts the app in Applications. By @crmne ([packaging change](https://github.com/crmne/chatwithwork-local-agent/commit/564a9b7)); thanks @crmne for reporting the missing AUR launcher.
- **Agent startup has a clear path.** Per-user Windows and Scoop installers start the agent now and at login. The macOS package attempts setup for the logged-in user, and the macOS/Linux one-line installer attempts it for the installing user. If setup cannot run, the instructions explain how to recover. System-wide Linux packages tell you to choose **Start Local Agent** in the app or run `cww daemon install` as your own user, without `sudo`. Install and upgrade messages also explain status checks and restarting after an update. Nothing is shared until you pair and choose a folder. By @crmne.
- **Linux packages install the GUI's graphics dependencies.** Homebrew and Nix also supply the library paths the desktop app needs. The macOS Homebrew formula keeps the daemon registered through a stable path across upgrades. By @crmne.

## Known limitations

- **Linux GUI packages need glibc 2.35 or newer:** Ubuntu 22.04+, Debian 12+, Fedora 36+, or Rocky/RHEL 10+. The separate static `cww` archives remain available for terminal-only use on older systems. A tray supporting StatusNotifierItems keeps the app available when its window closes.
- **The Windows builds and macOS `.pkg` are still unsigned.** Windows may show a SmartScreen warning. On macOS, use the signed and notarized `.dmg` or Homebrew if Gatekeeper refuses the `.pkg`.
- **WinGet and Scoop catalog submissions are separate from this release.** Their updated manifests are included in the packaging archive; the direct MSI is available immediately. AUR and Homebrew updates are published by the release workflow.
- **Nix on Intel macOS is unavailable with the pinned Nixpkgs.** Use the universal macOS download or Homebrew there. Nix supports Linux on both architectures and Apple silicon macOS.
- **The desktop app does not update itself.** Upgrade through your package manager or download the next release. After upgrading a Linux package, run `systemctl --user restart cww.service` to restart an enabled agent.
