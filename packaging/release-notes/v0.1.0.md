The first release of the Chat with Work Local Agent: `cww` lets Chat with Work search and read the folders you choose on your Mac, Windows PC or Linux machine, and nothing else.

- Four read-only tools (`roots`, `search`, `list`, `read`) over one outbound WebSocket. No port is opened on your computer.
- A local full-text index that updates from file events and sleeps while nothing changes.
- Secrets stay private even inside shared folders: SSH keys, `.env` files, keychains, password databases and browser profiles are on a built-in deny list.
- Every request is written to a local audit log you can follow live in the terminal UI or with `cww log -f`.
- A terminal UI (`cww`) to pair, share folders, pause, and watch activity.

Install with Homebrew (`brew install crmne/tap/cww`), the per-user MSI or `.pkg`, `.deb` and `.rpm` packages, the AUR, Nix, or the one-line installers. See the README for each.
