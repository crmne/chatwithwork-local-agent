The Local Agent now starts without administrator access on Windows and waits for a previous agent to stop on macOS. The welcome page is centered, and the app has a seamless window header.

**Download:** [macOS app](https://github.com/crmne/chatwithwork-local-agent/releases/download/v0.3.1/chat-with-work-v0.3.1-macos-universal.dmg), [Windows installer](https://github.com/crmne/chatwithwork-local-agent/releases/download/v0.3.1/cww-v0.3.1-x86_64-pc-windows-msvc.msi), [Debian/Ubuntu package](https://github.com/crmne/chatwithwork-local-agent/releases/download/v0.3.1/chatwithwork-local-agent_0.3.1_amd64.deb), or [Fedora/RHEL package](https://github.com/crmne/chatwithwork-local-agent/releases/download/v0.3.1/chatwithwork-local-agent-0.3.1-1.x86_64.rpm). Arm builds and portable archives are in the release assets. On Arch, upgrade `chatwithwork-local-agent-bin`; on macOS, use `brew upgrade --cask chat-with-work`.

## New

- **One continuous window header.** The app draws its header in the current theme. macOS keeps its native traffic lights, aligned with Fast Frame; Windows and Linux get integrated minimize, maximize and close controls, with dragging and edge resizing. Closing the window keeps the agent running. By @crmne ([interface change](https://github.com/crmne/chatwithwork-local-agent/commit/9e26da7)).

## Fixed

- **Start Local Agent works when Windows denies Task Scheduler access.** Setup falls back to your account's Startup folder and starts the agent immediately, without asking for administrator rights. The shortcut starts it again at login and is removed during uninstall. By @crmne ([startup fix](https://github.com/crmne/chatwithwork-local-agent/commit/f98b874)); thanks @crmne for reporting the Windows failure.
- **Restarting the agent on macOS waits for the old service to finish stopping.** This avoids the brief registration race that could show an exit-code-5 error and suggest root access. By @crmne; thanks @crmne for the Mac report and diagnosis access.
- **The welcome page stays centered as you resize the window.** The setup cards move together while their instructions remain left-aligned. By @crmne; thanks @crmne for reporting the layout issue.

## Known limitations

- **The Windows Startup fallback starts at login but does not restart after a crash.** If needed, open the app and choose **Start Local Agent**. Installations using Task Scheduler retain automatic restart.
- **Windows builds and the macOS `.pkg` remain unsigned.** The macOS `.dmg` is signed and notarized. Linux GUI packages require glibc 2.35 or newer.
- **The app does not update itself.** Upgrade through your package manager or download this release. After upgrading an enabled Linux service, run `systemctl --user restart cww.service`.
