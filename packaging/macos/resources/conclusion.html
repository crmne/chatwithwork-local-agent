Chat with Work is installed. Open Chat with Work in Applications, or run cww in Terminal for the terminal interface.

It pairs this Mac with Chat with Work and asks which folder to share. Nothing is shared until you say so.

The installer starts the background agent for the logged-in user and registers it for future logins. If no user was logged in, or startup failed, open the app and choose Start Local Agent. You can also run cww daemon install as your own user. Check it with cww status.

macOS asks once whether cww may access your Documents folder. Allow it, or share a folder elsewhere.
